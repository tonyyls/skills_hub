**实施范围**

* 建立 `vue-i18n` 技术框架。

* 首批页面国际化：首页（HomePage）、技能（SkillsPage）、教程（TutorialPage）、详情（SkillDetailPage）、登录（AdminLogin/相关登录页面）。

**核心步骤**

* 引入依赖并初始化：创建 `src/i18n.ts`，`src/locales/zh-CN.json` 与 `src/locales/en.json`，在 `src/main.ts` 注册。

* 默认语言检测与持久化：基于 `navigator.languages`/`navigator.language`，`localStorage('app_locale')` 保存用户选择。

* 路由标题国际化：将现有中文 `meta.title` 改为 `meta.titleKey`（如 `pages.home.title`），在 `beforeEach` 中通过 `t` 设置 `document.title`。

* 日期本地化同步：建立 `syncDayjsLocale()`，随语言切换同步 `dayjs.locale()`。

* 页内文案替换：将页面内中文硬编码改为 `t('...')`。

* 语言切换组件：`LanguageSwitcher.vue`，支持中英文切换与 `html[lang]` 设置。

**关键代码（示例）**

```ts
// src/i18n.ts
import { createI18n } from 'vue-i18n'
import zhCN from '@/locales/zh-CN.json'
import en from '@/locales/en.json'

function detectDefaultLocale(): string {
  const saved = localStorage.getItem('app_locale')
  if (saved) return saved
  const langs = navigator.languages?.length ? navigator.languages : [navigator.language]
  const cand = (langs || []).map(l => l.toLowerCase())
  if (cand.some(l => l.startsWith('zh'))) return 'zh-CN'
  return 'en'
}

export const i18n = createI18n({
  legacy: false,
  locale: detectDefaultLocale(),
  fallbackLocale: 'en',
  messages: { 'zh-CN': zhCN, en }
})

export function setLocale(locale: 'zh-CN' | 'en') {
  i18n.global.locale.value = locale
  localStorage.setItem('app_locale', locale)
}
```

```ts
// src/main.ts（注册）
import { i18n } from '@/i18n'
app.use(i18n)
```

```ts
// src/router/index.ts（标题）
router.beforeEach((to, from, next) => {
  const { t } = useI18n()
  const key = (to.meta.titleKey as string) || 'common.appTitle'
  document.title = t(key)
  next()
})
```

```ts
// src/plugins/dayjs.ts
import dayjs from 'dayjs'
import 'dayjs/locale/zh-cn'
import { i18n } from '@/i18n'
export function syncDayjsLocale() {
  dayjs.locale(i18n.global.locale.value === 'zh-CN' ? 'zh-cn' : 'en')
}
```

```vue
<!-- src/components/LanguageSwitcher.vue -->
<template>
  <select v-model="current" @change="onChange">
    <option value="zh-CN">中文</option>
    <option value="en">English</option>
  </select>
</template>
<script setup lang="ts">
import { ref, watchEffect } from 'vue'
import { setLocale, i18n } from '@/i18n'
const current = ref(i18n.global.locale.value as 'zh-CN' | 'en')
function onChange() { setLocale(current.value) }
watchEffect(() => { document.documentElement.setAttribute('lang', current.value === 'zh-CN' ? 'zh' : 'en') })
</script>
```

**页面改造要点**

* 首页（`src/pages/HomePage.vue`）：主标题、副标题、搜索框占位符、按钮与提示改为 `t` 键；如需渲染 Markdown，保持与文案分离。

* 技能（`src/pages/SkillsPage.vue`）：页面标题、空状态文案、筛选控件标签与提示语改为 `t` 键。

* 教程（`src/pages/TutorialPage.vue`）：页面标题与介绍说明改为 `t` 键；若内容来自 Markdown 文件，后续可按语言拆分。

* 详情（`src/pages/SkillDetailPage.vue`）：页面标题、作者、更新时间等元信息标签改为 `t` 键；日期展示使用 `dayjs` 同步语言。

* 登录（`src/views/AdminLogin.vue` 及相关）：标题、登录/退出按钮、错误提示与表单标签改为 `t` 键。

**验证清单**

* 语言自动检测正确（中文系统默认中文、英文系统默认英文）。

* 切换语言后：页面文案、路由标题、`html[lang]` 与 `dayjs` 语言同步。

* `localStorage('app_locale')` 持久化与刷新一致。

* 性能符合预期；如需进一步优化，改为按语言动态导入字典。
