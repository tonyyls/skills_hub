# 系统功能清单

## 简介

* Skills Hub 是一个第三方技能聚合平台，提供技能浏览、筛选和收藏；管理端提供分类与技能管理、AI 辅助识别与批量自动化功能；数据层基于 Supabase，后端基于 Express（支持 Vercel Functions 入口与本地执行）。

## 用户端功能

* 首页

  * 搜索框：输入后回车跳转到搜索结果；支持清空按钮（src/pages/HomePage.vue:42-75,365-376）

  * 最新/精选切换：固定“3行可见”，随断点计算列数（src/pages/HomePage.vue:115-213,327-345）

  * 卡片展示：标题、精选徽章、描述多行省略、标签最多3个、分类与作者（src/pages/HomePage.vue:147-210）

* 技能列表页

  * 分类筛选与计数（src/pages/SkillsPage.vue:51-81,580-593）

  * 分页固定每页 24 项（6行×4列）（src/pages/SkillsPage.vue:281-283）

  * 网格卡片与收藏：星标高亮、加入/取消收藏（src/pages/SkillsPage.vue:132-200,361-439）

* 技能详情跳转

  * 首页与列表页卡片点击进入详情（src/pages/HomePage.vue:143-146, src/pages/SkillsPage.vue:576-578）

## 管理端功能

* 登录与权限

  * 管理员登录发放 JWT；所有管理端接口通过 Authorization Bearer 鉴权（api/routes/admin.ts:77-105,111-220）

* 分类管理

  * 列表/搜索/创建/更新/删除；异常降级至本地 devStore 保证可用（api/routes/admin.ts:241-452）

* 技能管理

  * 列表（分页、搜索、筛选），创建、更新、删除；保存时刷新分类计数（api/routes/admin.ts:455-749,661-724,731-754,975-995）

  * 编辑模态：分类、作者、源信息、标签、内容、状态；从 Git 同步 SKILL.md；预览（src/views/AdminSkills.vue:302-607）

* AI 识别（表单内）

  * “AI识别”卡片：开始识别→分类与标签建议（最多3个）；应用到表单；每次打开编辑清空状态（src/views/AdminSkills.vue:320-371,1368-1407,982-986,1037-1045,1307-1313）

* 批量自动化

  * 批量自动分类与打标签接口：`POST /api/admin/ai/auto-classify`（limit 默认50、最大200；minConfidence 默认0.6）（api/routes/admin.ts:新增批处理接口区域）

* 友情链接管理

  * 列表/创建/更新/删除（api/routes/admin.ts:1568-1740）

* 用户管理

  * 真实站点用户（Supabase Auth）：列表、创建、更新、删除；与 user\_profiles 合并显示（api/routes/admin.ts:1002-1344）

## AI 自动化能力

* 提供方封装（GLM-4.6）

  * 统一接口：`AiProvider` / `AiService`；分类 + 标签（最多3个）结构化返回（api/utils/ai.ts:1-44）

  * 标签要求差异化、短语化、去重；分类从当前类目集合中选择；仅使用“标题+描述”作为输入（api/utils/ai.ts:14-25,27-33）

* 表单内识别接口（单条）

  * `POST /api/admin/skills/:id/ai-classify`；支持懒初始化读取 `GLM_API_KEY`；日志输出识别结果（api/routes/admin.ts:表单识别路由位置）

* 批量识别接口（本地执行）

  * `POST /api/admin/ai/auto-classify`：查询未分类技能→识别→满足阈值写回分类与合并标签（最多追加3个）（api/routes/admin.ts:新增循环与写回逻辑）

## 接口清单（主要）

  * `GET /api/admin/me`（api/routes/admin.ts:226-235）

* 分类

  * AI 识别：`POST /api/admin/skills/:id/ai-classify`（api/routes/admin.ts:AI 单条识别路由）

  * 批量自动化：`POST /api/admin/ai/auto-classify`（api/routes/admin.ts:AI 批处理路由）

* 友情链接

  * `GET /api/admin/links`、`POST /api/admin/links`、`PUT /api/admin/links/:id`、`DELETE /api/admin/links/:id`（api/routes/admin.ts:1568-1740）

* 用户

  * 真实站点用户：`GET/POST/PUT/DELETE /api/admin/users`（api/routes/admin.ts:1002-1344）

* 公共接口

  * 健康检查：`GET /api/health`（api/app.ts:41-49）

## 关键技术点

* 前端（Vue3 + TypeScript + Pinia + Vue Router）

  * 组合式 API、响应式布局、断点驱动的展示数量控制（固定行数 + 动态列数）

  * 卡片信息规范：标题、描述、省略、标签最多3个；收藏交互与轻量 Toast

* 后端（Express）与 Vercel Functions 入口

  * 路由设计、鉴权中间件（JWT）、容错与降级（devStore）

  * 懒初始化读取环境变量（`GLM_API_KEY`）避免 `.env` 加载顺序问题（api/routes/admin.ts: - getAiService()）

* 数据层（Supabase）

  * Service Role Key 服务端访问；`users/user_profiles` 合并；分类计数视图刷新

  * RPC 调用与物化视图：发布状态/分类变更时刷新计数（api/routes/admin.ts:645-650,713-719）

* AI 结构化输出

  * GLM JSON 输出模式，严格返回分类与标签结构，标签不超过3个，差异化与去重（api/utils/ai.ts:14-33）

* 性能与可靠性

  * 批处理接口控制 `limit` 与 `minConfidence`；仅使用标题+描述缩短上下文；日志打印统计

## 环境变量

* `.env`（本地）与 `.env.example`

  * `GLM_API_KEY`：GLM-4.6 提供方密钥（仅后端使用）

  * `VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`：前端 Supabase 访问

  * `SUPABASE_SERVICE_ROLE_KEY`：服务端 Supabase 密钥（切勿暴露到前端）

  * `ADMIN_JWT_SECRET`、`ADMIN_USERNAME`、`ADMIN_PASSWORD`

## 运行与本地批处理指南

* 启动服务（本地）

  * `npm run server:dev`（dev-server/server.ts:9-25）

* 管理员登录获取 token 并执行批量识别

  * `POST /api/admin/login` → 获取 token

  * `POST /api/admin/ai/auto-classify` → 传 `{"limit": 50, "minConfidence": 0.6}`

* 查看结果与日志

  * 返回 `{ total, updated, lowConfidence, errors }`；服务端日志打印 `[ai-auto-classify] {...}`
